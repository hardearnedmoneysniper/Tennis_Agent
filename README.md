# 🎾 Tennis Agent — 网球动作分析教练

上传一段网球视频，自动分析击球动作、估算水平、指出优先改进点，并生成两周训练计划。

- 视频 → MediaPipe 人体姿态 → 击球检测与分类 → 生物力学指标 → 评分
- Claude（多模态）看关键帧 + 指标，生成教练反馈和训练计划
- 没有 API Key 时自动使用本地规则教练，全流程仍可跑通
- 本地网页界面：标注视频、关键帧、雷达图、指标卡、训练计划、追问对话

> 说明：当前版本基于单机位人体姿态估计，不追踪球和球拍，无法测量球速、旋转和落点。
> 所有建议仅供训练参考，不能替代现场教练或医学诊断。

## 快速开始

```bash
cd X:\Tennis_Agent
pip install -r requirements.txt
python app.py
```

打开 http://127.0.0.1:7860，上传视频并填写球员信息即可。

### 配置 Claude（可选，但推荐）

任选一种方式：

1. 启动前设置环境变量：

```bash
set ANTHROPIC_API_KEY=sk-ant-...
python app.py
```

2. 打开网页后，点击右上角「Claude 设置」，粘贴 API Key（只保存在当前服务进程内存中，不写入磁盘）。

默认模型是 `claude-opus-5-5`，可以用环境变量覆盖：

```bash
set TENNIS_LLM_MODEL=claude-sonnet-5-5
```

未配置 Key 或调用失败时，会自动回退到本地规则教练，并在报告顶部标明。

## 命令行用法

```bash
python -m tennis_agent.cli your_video.mp4 --hand right --goal "稳定正手击球点"
```

输出保存在 `outputs/<任务ID>/`：

- `report.md`：中文分析报告
- `annotated.mp4`：骨骼与触球点标注视频（已转成 H.264，浏览器可直接播放）
- `keyframes/`：关键帧
- `result.json`：完整结构化结果

网页端也可以直接用 `http://127.0.0.1:7860/?job=<任务ID>` 打开历史报告，服务重启后仍能读取已保存的结果。

## 拍摄建议（很重要）

- 固定机位，侧后方约 45°，手机横屏或竖屏都可以，但全程不要移动
- 全身入镜，人物至少占画面高度一半
- 光线充足，避免逆光和复杂背景
- 每个动作连续做 5–10 次，方便比较稳定性
- 建议穿贴身衣物，姿态识别会更稳

## 能分析什么

| 击球 | 指标 |
| --- | --- |
| 正手 | 击球点高度/前后/横向位置、触球肘角、肩髋分离角、站位宽度、屈膝、腕速、随挥高度、重心偏移 |
| 反手 | 击球点位置、肘角、转体、站位、屈膝、腕速、随挥、平衡 |
| 发球 | 击球点高度、肘角、屈膝、抛球手伸展、肩部倾斜、蹬伸幅度、腕速 |
| 高压 | 击球点高度、肘角、屈膝、腕速、平衡 |

评分是把实测指标与业余球员参考区间对比后得到的 0–100 分，并估算一个 NTRP 区间。
参考区间是通用教练经验值，不是针对个人身体条件的处方。

## 架构

```text
视频
 └─ video_io.py        读取、旋转、抽帧
     └─ pose.py        MediaPipe Pose 33 关键点
         └─ strokes.py 腕速峰值 → 击球检测 / 正反手·发球分类 / 阶段切分
             └─ metrics.py 关节角度、转体、击球点、稳定性 → 0-100 评分
                 ├─ visualize.py 标注视频 + 关键帧
                 └─ coach.py     Claude 多模态反馈 / 本地规则教练
                     └─ app.py + web/   Flask API + 单页界面
```

## 主要文件

- `app.py`：Flask 服务、任务队列、上传与查询接口
- `tennis_agent/pipeline.py`：分析流水线编排
- `tennis_agent/metrics.py`：指标定义、参考区间、评分与水平估算
- `tennis_agent/coach.py`：Claude 提示词、结构化输出、本地规则教练
- `web/`：上传页与分析报告界面

## 已知限制与下一步

- 未追踪球和球拍：触球点由腕速峰值与手臂伸展近似，无法判断真实击球瞬间
- 单机位 2D 投影会影响“身前距离”等指标的精度，建议尽量用侧后方 45° 机位
- 默认只分析视频前 120 秒，避免长视频处理过慢
- 下一步可接入 TrackNet/YOLO 做球与球拍追踪、教练知识库 RAG、动作模板对比（DTW）

## 常见问题

**MediaPipe 导入时报 DLL 错误？**
请确认使用的是 `mediapipe==0.10.14`。更新版本在部分 Windows/Anaconda 环境会加载失败，`requirements.txt` 已固定该版本。

**标注视频在浏览器里打不开？**
标注视频会通过项目内的 `imageio-ffmpeg` 转成 H.264。如果转码失败，页面会提供下载入口；也可以直接用本地播放器打开 `outputs/<任务ID>/annotated.mp4`。

**Claude 一直没有被调用？**
报告顶部会显示当前反馈引擎。未配置 `ANTHROPIC_API_KEY` 时使用本地规则教练；在网页右上角「Claude 设置」填入 Key 后，重新分析即可。Key 只保存在当前服务进程内存中。
