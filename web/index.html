个人击球分析

把这一拍，
拆开看。

上传一段击球视频。姿态识别找出每一次挥拍，量化击球点、转体、屈膝和平衡，再生成一份能照着练的两周计划。

  1. 01
    拍一段清楚的视频

    固定机位，侧后方 45°，全身入镜，连续 5–10 个同类击球。

  2. 02
    看见动作里的数字

    每一拍拆成准备、引拍、触球、随挥，和业余球员参考区间对比。

  3. 03
    拿到下一步练什么

    优先改进点、具体练习、组数和两周训练安排。

视频与姿态数据只在本机处理；配置 Claude 后，关键帧和指标会发送给 Claude API 生成反馈。

拍摄条件比设备更重要

机位三脚架固定，侧后方约 45°，别跟着人转。

取景从脚到拍头都在画面里，人物占画面高度一半以上。

内容同类击球连续 5–10 次，中间不要捡球和走位。
