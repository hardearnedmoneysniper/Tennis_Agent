🎓 教练视频（你的核心数据资产）

你拥有的学院派教练视频是让 Agent 从"通用分析"升级到"专业教练水平"的关键。

教练视频内容可提取什么融入方式
🎙️ 口头讲解 技术要点、常见错误、纠正口诀 Whisper 转录 → Claude 结构化 → 向量知识库
🕺 标准示范 理想姿态序列（关键点坐标） MediaPipe 提取 → 作为对比基准
❌→✅ 错误 vs 正确对比 典型错误的姿态偏差模式 姿态差异向量 → 自动匹配你的错误类型
🏋️ 训练方法演示 针对性练习步骤 存入知识库 → 反馈时推荐训练方法

🔬 管线 A：你的视频 → 动作分析

  1. 视频帧提取
    OpenCV 输入：.mp4 输出：帧序列 (numpy)

    按 15-30 FPS 抽帧，去模糊帧自动跳过。

  2. 人体姿态估计
    MediaPipe Pose 输出：33个关键点 × 3D (x,y,z,visibility)

    肩、肘、腕、髋、膝、踝等 33 个身体关键点，每帧一组。

  3. 球 & 球拍追踪
    TrackNet / 色块追踪 输出：球轨迹 (x,y,t) + 拍头轨迹
  4. 击球事件检测
    基于手腕/拍头速度突变 输出：每次击球的时间戳
  5. 击球类型分类
    规则 + 姿态特征 输出：正手 / 反手 / 发球 / 截击 / 高压
  6. 动作阶段切分

    每个击球拆为 5 个阶段：
    准备姿势 → 引拍 → 前挥 → 触球 → 随挥

  7. 生物力学指标计算
    动作关键指标
    🏐 发球抛球高度偏差 · 膝曲角 · 肩外旋角 · 击球点高度 · 躯干后仰角
    🎾 正手身体转体幅度 · 肘部与身体距离 · 击球点前后位置 · 随挥高度 · 重心转移
    🔙 反手肩部转动角 · 非持拍手引导 · 击球点位置 · 重心转移
    🦶 步法分腿垫步时机 · 回位速度 · 移动中击球稳定性

🎓 管线 B：教练视频 → 结构化知识库

  1. 音频提取
    ffmpeg 输入：教练 .mp4 输出：.wav 音频
  2. 语音转文字
    OpenAI Whisper 输出：完整逐字稿

    本地运行，免费。支持中英文。large-v3 模型精度最高。

  3. 知识点结构化提取
    Claude API 输出：结构化知识卡片 JSON

知识卡片 Schema

{
  "coach": "张教练",
  "stroke": "正手",
  "phase": "引拍阶段",
  "aspect": "手臂位置与发力空间",

教练示范姿态提取

教练做标准示范时，同样跑 MediaPipe 提取关键点序列，作为"理想基准"。

教练示范视频片段 → MediaPipe → 标准姿态关键点序列
存入知识库，标注"这是 XXX 教练的标准正手引拍"
分析你的视频时，做姿态序列对齐（DTW），计算逐帧偏差

向量知识库构建

所有知识卡片 → embedding（文本向量化）
存入向量数据库（ChromaDB / LanceDB）
分析时按语义检索相关教练建议

🎾 发球分析报告

🔴 优先级 1：抛球高度不足（-25cm）

你的抛球平均 2.35m，低于理想的 2.60-3.00m。如张教练所说：「抛球要有停顿感，球到最高点再出手」。抛球偏低会导致你仓促击球，被迫降低击球点，损失力量和稳定性。

本周训练：每天做 50 次抛球练习——只抛不击，要求球每次落在身体前方同一位置，用胶带在地面标记落点范围。

🟡 优先级 2：膝关节发力参与不足

膝曲仅 62°，李教练强调：「没有腿就没有发球」。你的下肢力量没有充分传递到击球。建议做慢动作发球练习，专注于"蹬地→转髋→挥臂"的动力链顺序。

✅ 做得好的：肩外旋幅度在合理范围，说明你的肩部柔韧性不错，保持！

💡 关键设计决策

❌ 不做的

  • 训练自己的姿态估计模型 → 用 MediaPipe 足够
  • 收集海量标注数据 → 不需要
  • 写死规则库 → 让 LLM 做推理
  • 依赖 GPU → 全流程 CPU 可跑
  • 职业球员视频对比 → 先用内置参考值

✅ 核心思路

  • 预训练模型做感知（MediaPipe / Whisper）
  • 经典算法做度量（角度、距离、DTW）
  • LLM 做理解和表达（Claude）
  • 教练视频是你最独特的数据壁垒
  • 中文输出，接地气的教练口吻
🎯 核心壁垒：通用姿态分析谁都能做，但你的教练视频知识库让反馈有了专属教练的教学风格和独特经验——这才是这个 Agent 的真正价值。
